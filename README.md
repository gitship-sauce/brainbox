# Brainbox

A personal knowledge base, built one episode at a time in the Gitship Sauce series
"Build Your Second Brain in Python".

Each episode has a git tag (`ep01`, `ep02`, ...). Check out the tag to get the code as it
was at the end of that episode. Cards for each episode are in `cards/`.

## Run

Python 3.10 or newer. No packages needed yet.

```
python3 brainbox.py
```
