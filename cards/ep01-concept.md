# Concept Card: Python dictionaries and lists

- **What it is:** a dictionary is a set of named values (keys and values); a list is an ordered row of values.
- **When to use it:** a dictionary when one thing has several named parts; a list when you have many of the same thing.
- **What you'll build:** a note as a dictionary, all your notes as a list of dictionaries, and a program that adds a note and shows every note.
- **What to remember:** `note["title"]` reads one part; `notes.append(note)` adds a note to the end; `for note in notes:` visits every note. A dictionary uses a key name in square brackets; a list uses a position number.
- **Try it yourself:** add a `"created"` key to each note and print it with the others.
