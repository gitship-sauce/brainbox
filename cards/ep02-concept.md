# Concept Card: Python functions

- **What it is:** a function is a named box of steps; `def` writes the box, and calling its name runs the steps.
- **When to use it:** when a job has a name, like add a note, or when the same lines appear in two places.
- **What you'll build:** a menu where each choice calls a function: add, show, edit and delete.
- **What to remember:** a function runs only when it is called. A value in the brackets is a parameter; `return` hands a value back.
- **Try it yourself:** write `show_titles()` that prints only the titles, and add it to the menu as choice 6.
